# Layoffs Data Exploratory Analysis (SQL)

An exploratory data analysis project using MySQL to investigate company layoffs and identify patterns across companies, industries, countries, and time periods.

## Overview

This project explores a dataset of company layoffs using SQL queries, progressing from basic data exploration to more advanced querying techniques. The analysis focuses on summarizing the data and identifying trends within reported layoffs.

## Development Context

**Guided Learning Project**

Completed as part of structured SQL learning through instructional material. The project provided hands-on practice applying SQL techniques to a real-world dataset.

## Tools & Technologies

- MySQL
- SQL
- Exploratory Data Analysis (EDA)

## Features

- Explores and summarizes company layoff data.
- Identifies companies with the largest reported layoffs.
- Examines layoffs across industries and countries.
- Analyzes layoffs over time.
- Uses aggregate functions and grouping.
- Applies more advanced SQL queries for exploratory analysis.

## Files

- `20. Exploratory Data Analysis.sql` - SQL script containing the exploratory queries.

## Learning Objectives

- Practice SQL querying and data exploration.
- Apply aggregate functions and grouping.
- Develop familiarity with more advanced SQL techniques.
- Identify trends and summarize information from a real-world dataset.
