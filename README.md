# Layoffs Data Exploratory Analysis (SQL)

An exploratory data analysis project using SQL to investigate company layoffs, identify trends, and examine patterns across industries, companies, and time periods.

## Overview

This project uses SQL queries to explore a dataset of company layoffs. The analysis progresses from basic data exploration to more advanced SQL techniques to uncover trends and summarize patterns within the dataset.

## Tools & Technologies

- MySQL
- SQL
- Exploratory Data Analysis (EDA)

## Features

- Explores and summarizes company layoff data.
- Identifies companies with the largest reported layoffs.
- Examines layoffs across industries and countries.
- Analyzes layoffs over time.
- Uses aggregate functions and grouping to identify trends.
- Applies more advanced SQL queries and techniques for deeper analysis.

## Files

- `20. Exploratory Data Analysis.sql` - SQL script containing the exploratory queries and analysis.

## Purpose

To strengthen SQL skills through hands-on exploratory data analysis, progressing from foundational queries to more advanced techniques for investigating real-world datasets.
